## 📚 What I Learned

Today I learned how to work with **Nested Dictionaries** in Python.

A nested dictionary is a dictionary that contains another dictionary inside it.

## 🧠 Concepts Practiced

* Creating nested dictionaries
* Accessing values from nested dictionaries
* Using multiple keys to access data
* Updating values inside nested dictionaries
* Using `for` loops with dictionaries
* Using `.items()`

## 🧑‍🎓 Mini Task

I created a simple student record containing information for multiple students.

Example:

```python
student = {
    "student1": {
        "name": "Rajesh",
        "course": "Python",
        "mark": 90
    },
    "student2": {
        "name": "Arun",
        "course": "Python",
        "mark": 75
    }
}
```

I practiced accessing information such as:

```python
student["student1"]["name"]
student["student1"]["mark"]
```

I also learned how to update a value inside a nested dictionary:

```python
student["student1"]["mark"] = 95
```
